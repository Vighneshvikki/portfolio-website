# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website showcasing my skills, projects, and internship experience. The website was developed to establish a professional online presence and highlight my technical abilities.

## 🚀 Features

* Responsive design for mobile, tablet, and desktop
* Modern dark-themed UI with glassmorphism effects
* Hero section with introduction
* Skills section
* Projects showcase
* Internship experience
* Resume download section
* Contact information and social links
